Scope
The user's goal remains a thorough, application-wide performance improvement
effort. This record describes one batch, not proof that optimization is exhausted.
The production desktop runs NSH (nsh_main.rs); legacy GPUI source and its older
performance reports are reference material, not measurements of the current UI.
Existing panel/settings edits and concurrent external edits were preserved.

Changes in this batch
* Shared Mac/iOS project tree: index children and owned projects, count each
  subtree once, and use iterative traversal for deep nesting and cycle repair.
* Workspace snapshots: tab metadata/indexing investigation and changes in
  apps/riwork/src/lib.rs: borrow per-projection entry/shell indexes, reuse the
  pane metadata for shared tabs, precompute ranks, and move built JSON arrays.
* Engine transcript projection: index request assignment by turn/item rather
  than repeatedly scanning history; preserve legacy and malformed associations.
* Chat logs: use the existing memchr dependency for newline counting and reverse
  search, and reuse the reverse-scan buffer.
* Native Files: reuse lowercase sorting keys; seek into ordered Git-status maps
  for descendant badges; share one lazily read Git status per watcher batch.
  This cache lasts only the batch, so a later refresh still gets fresh status.
* Native snapshot hub: move the new snapshot into the retained slot and avoid
  cloning payloads for already closed listeners.
* Remote terminal screen deltas: retain immutable screens through Arc while
  comparing outside the shared device-table lock; reuse shift costs instead of
  rescanning; copy full output into JSON only when no delta is sent.

  candidate ~1.08 ms. A 10,000-deep candidate completes without recursion overflow.
  In the actual NSH JS engine, 100 nested folders measured 169 -> 1 ms

  This is not a measured full replay/load improvement.
* Engine cached projection, 6,000 items / 1,500 requests, debug test executables:

  169.147/20.848, 162.632/19.989, 168.767/20.180. Medians 168.767/20.180,
